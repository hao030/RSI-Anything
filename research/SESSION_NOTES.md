## 1. 背景：师兄的建议

**读论文**
- 以前的读法：先看图，再看摘要，最后看实验和方法细节。现在不用读那么细，抠细节没必要。
- 先筛选：好论文作者会做宣传（talk、视频、公众号、小红书），几分钟就能看懂在做什么；有人认真宣传，本身就说明值得看。
- 让 AI 做对比阅读：从一篇出发找出相关几篇，纵向看时间发展，横向看不同方法，对比方法和效果，找共性和差异。
- 细节交给 AI，人负责高层判断，以及怎么用好 AI。

**上手**
- 读论文不是该花时间的部分，要尽快上手迭代，让 AI 帮忙快速实现 idea、复现工作。
- 好论文有一两篇就够，前提是尽量复现，追上效果，再在此基础上优化。
- 光看不够，自己动手才知道里面有什么问题。

**选方向**
- 组里资源撑不起训练相关的任务，所以做 benchmark / 评测集最现实：评测大模型在 specific 任务上的能力。
- 先写初步 proposal 再讨论。唐老师（T，唐彦嵩）很久没在一线了，给的指导会比较宽泛，具体方向要自己提。

**布置的三件事**
1. 围绕 RSI 找一个自己觉得有意思的 topic，整理相关工作：有影响力、以实验室产出为主（不以大厂为主）、有宣传、代码开源。
2. 结合唐老师的项目（端侧智能感知无人机、具身长程任务、低空灾害检测等），看 RSI 能在哪些场景结合、有什么价值。
3. 形成几个可行的 idea，按 1–5 排序：资源尽量少、方向比较新、做的人比较少。

## 3. 核心结论

**Topic：RSI 的「自评」瓶颈。** 代码、数学有执行器和标准答案，可以绕开自评问题；视觉、无人机、具身场景没有验证器，改进信号只能来自模型自己（多数投票、自己打分、自问自答、置信度、世界模型预测）。这些信号什么时候可靠、什么时候会把系统带偏，缺少系统研究。

**从 star 数看到的趋势**
- 文本 / 智能体方向已经很热（DGM 2.5k、Absolute Zero 1.9k、ADAS 1.7k、SPIN 1.3k、TTRL 1.1k）。
- 多模态自我进化还比较冷（Vision-Zero 194、VisPlay 80），论文发在 CVPR / ICLR 2026，但关注的人少，适合切入。
- 世界模型 + RSI 涨得最快（Dream-RSI 1.5k、RSI-Anything 1.0k），但都有企业或初创公司主导。

**建议精读并复现**：TTRL（流程最简单，「多数投票什么时候失效」就是 topic 核心）、VisPlay（多模态，贴合组里方向）；备选 Ranked from Within（无官方代码，但只用推理，自己实现成本低）。

**唐老师组背景**：清华深圳国际研究生院 Intelligent Vision Group，方向是视频理解 + 智能体推理。代表作 VITAL / Thinking With Videos（arXiv 2508.04416）、StableVLA（arXiv 2605.18287）。注意：OpenFly 不是唐老师组的工作（已核对作者列表）。

**Idea 排序**

| # | Idea | 资源 | 是否需要训练 |
| :--- | :--- | :--- | :--- |
| 1 | 低空场景下 VLM 自评可靠性 Benchmark（首推，主数据用 UrbanVideo-Bench） | 低 | 否 |
| 2 | 灾害场景的无标签模型选择 | 低 | 否 |
| 3 | 靠经验自我进化的无人机长程任务智能体 | 中低 | 否 |
| 4 | 按置信度挑样本的端云协同自我改进 | 中 | 少量 LoRA |
| 5 | 无人机视频上的自问自答自我进化（可用组里的 DGRPO） | 高 | RL |

**最新补充**：HarnessPro（arXiv 2610.26770，清华唐杰 / 赵虹组，在审，代码 `pzs19/HarnessPro`）用 LLM 生成的测试代替标准答案来递归改进 agent harness，和「自评瓶颈」直接相关：LLM 生成的测试本身靠不靠得住，论文应该分析得不多（只读了摘要，待读正文确认）。
